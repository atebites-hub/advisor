# Advisor orchestration

Read and follow the installed `orchestration` skill. On Cursor IDE and Cursor CLI,
declare the route before task tools. Prefer multitask when that is the right
native tool. ODW must still align with multitask; unused ODW is not a
soft-green pass. Alignment is unproven until live fixtures. Use `solo` unless
`doctor --host cursor` reports a proven native or ODW lane. Do not treat
plugin settings, Task `subagent_model`, or `agent --model` as attestation.
